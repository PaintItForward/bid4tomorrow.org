# Bid For Tomorrow

Bid For Tomorrow is a nonprofit organization using student art and online auctions to support youth physical and mental health.
Website: https://bid4tomorrow.org/

## About

Bid For Tomorrow provides a platform for student artists to showcase and sell their artwork through auctions. A portion of proceeds supports youth-focused causes, while artists can also benefit from the sale of their work.

Our branches currently include:

* Toronto, Ontario
* Lexington, Massachusetts

## Website

The website contains:

* Information about Bid For Tomorrow
* Artist and artwork listings
* Online art auctions
* Artwork detail pages
* User registration and login
* Bidding functionality
* Bid history
* Auction information and updates

## Tech Stack

* HTML, CSS, JavaScript
* Supabase
* Supabase Authentication
* Supabase PostgreSQL database
* GitHub for version control and deployment
* Resend for transactional email
