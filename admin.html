Auctions

Loading…

Create always produces a draft auction; use Open to make it live. Edit updates title / description / dates / status (but not status closed). Close determines winners and only succeeds after ends_at has passed. Reopen is available only for closed auctions with no winners. Delete is allowed only when there are no bids and no winners, and it also deletes the auction's lots (cascade). Artworks are not deleted.
